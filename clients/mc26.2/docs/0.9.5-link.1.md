# GUMIHO 0.9.5-link.1 — local Link test candidate

Not the final 1.0 release. This candidate adds Link to the accepted 0.9.2 gameplay/HUD baseline.
Elytras, fishing and crystal PvP remain deferred. No server/game files or existing user configs
were changed during development.

## Choose one JAR per Minecraft instance

- Full GUMIHO: gumiho-neoforge-0.9.5-link.1-mc1.21.1.jar or the mc26.2 JAR.
  Includes all existing modules plus Link.
- Teammates: gumiho-link-0.9.5-link.1-mc1.21.1.jar or the mc26.2 JAR.
  Contains Link only: no aim, attack, bridge, combat HUD modules, mixins or GUMIHO presets.
- Do not install full GUMIHO and Link-only together. Both declare gumiho_link;
  NeoForge rejects duplicate mod IDs. Replace your previous GUMIHO JAR; retain it outside mods for rollback.
- Minecraft 1.21.1 uses Java 21 / NeoForge 21.1.248+. Minecraft 26.2 uses Java 25 / NeoForge 26.2.0.75+.
  Each JAR is restricted to its own Minecraft version. Neither belongs in the dedicated server's mods folder.

## Controls

| Default | Action |
| --- | --- |
| Right Alt (hold) | TAB-style Link panel; releasing hides it, movement stays available |
| Left Alt | Capture looked-at point (or own position in empty air), then choose ping kind/audience |
| F8 | Connection, Sharing, Ping and Team pages |
| Link settings > Keybinds | Opens Minecraft keybindings; change all three under GUMIHO Link |

The main GUMIHO menu also has a Link button on non-Combat pages.
Existing Minecraft key overrides are honored, not forcibly reset.
The hold panel truncates excess rows to stay on screen; F8 > Team offers previous/next
and Members/Pings views for all entries. Tooltips describe clipped controls.
Use a GUI scale yielding at least 320 x 240 logical pixels for the settings screen.

## What Link shares

Connection starts only when you explicitly press Save + Connect. It never auto-connects at launch.
The private team roster shows names, roles and online presence; these are shared when connected.
Location and stats audiences start empty. Sharing selects exact roles, independently per category:
Founder, Co-founder, Inner Circle, Officer, Member. No privileged visibility bypass.

Stats are your own health/max health, hunger, aggregate armor durability percent and held item IDs.
No inventory contents, enemies, nearby-player feed, combat commands or module controls are sent.
Names and stats are member-reported, not Mojang-verified.

Changing privacy settings disconnects and clears the panel immediately. Reconnect to apply.
The relay clears remote state when it receives the disconnect; otherwise live data expires after
five seconds. People cannot be made to forget information they already received.
A stopped game-data feed also suspends sharing. Network/auth errors clear cached data.

Sensitive data requires both players to have a fresh matching server address hash and dimension.
Address aliases may not match; use the same server-list address. The hash is not a secret.
Single-player telemetry and pings are disabled in this candidate (roster/connection testing still works).
A manual ping deliberately shares that point even with continuous location sharing OFF.
Select recipients each time; pings expire after 30 seconds and are rate-limited.

## Local relay setup — not yet a friends-over-the-Internet release

GUMIHO-Link/relay is a separate Node.js 24+ process. No npm packages are needed.
Run from that folder:

    node src/main.mjs --init private-bootstrap.json
    node src/main.mjs private-bootstrap.json private-membership.json 8791

The first command refuses to overwrite an existing bootstrap file.
The relay binds 127.0.0.1 only. It is not publicly reachable and no firewall/TLS deployment was performed.

1. Open F8 > Connect. Endpoint: http://127.0.0.1:8791.
2. Owner only: copy the bootstrap token from private-bootstrap.json into the masked key field,
   enter display name and new team name, then Join / Create.
3. Creation replaces that draft with your own member key and saves it. It does not connect or upload.
4. Press Save + Connect.
5. F8 > Team > Copy single-use invite. Send that invite privately to the intended member.
6. On another LOCAL test client, paste the invite, enter a display name, then Join / Create.
   Connect after joining. Invitations expire in ten minutes.
7. Use the Share page to choose exact recipient roles; reconnect after a change.

The relay cannot yet be used by friends on other PCs without a separately reviewed hosting/TLS setup.
Do not expose its development listener directly. HTTPS support in the client is not a deployment.

Client credentials are stored as plaintext in config/gumiho-link-private.json.
Keep that file private. It is separate from gumiho.json and excluded from all kit/HUD exports.
Do not include it in shared modpacks or post its contents. Forget member key disconnects and removes
the saved key; it does NOT revoke relay membership. Ordinary members must never receive the bootstrap key.
The relay stores token hashes and membership, not live telemetry. There is no end-to-end encryption claim.

## Acceptance checklist — user in-game test still needed

- Launch full and Link-only individually on each version; verify no duplicate mod installations.
- Check Right Alt hold/release, Left Alt ping chooser, F8, custom rebindings and restart persistence.
- Inspect 320x240 and 480x270 logical GUI layouts: no clipped footer, overlapping controls or hidden instructions.
- Verify saved kits/HUD layout and combat behavior remain unchanged from 0.9.2.
- Create/join a local team; sharing OFF should show roster but no location or stats.
- With two multiplayer clients on a LOCAL test server, allow MEMBER location but not stats; check exact visibility.
- Change dimension, disconnect, turn sharing off, stop relay, suspend a client: confirm old data disappears.
- Send each ping kind with selected roles, clear pings, check 30-second expiry.
- Confirm a Link-only client has no combat/automation controls.
- Do not treat successful compilation/HTTP tests as proof of live game behavior.

## Automated checks

Both native builds run existing combat, projectile, bridge, HUD, preset and startup regressions.
Link tests cover endpoint restrictions, bounded response bodies, no redirects, private settings,
local TTL expiry and a real Java-client/Node-relay exchange (independent audiences, role changes,
pings, context changes, frozen game feed, disconnect, credential revocation).
The separate relay suite covers all 25 role audience pairs, cross-team isolation,
epoch/sequence handling, limits and membership storage rollback.

Reproduce Java/relay integration from either source project with:

    gradlew build linkIntegration -PlinkNode=<absolute node executable> -PlinkFixture=<absolute GUMIHO-Link/relay/fixtures/java-fixture.mjs>

The test creates ephemeral loopback services/credentials and closes them. It does not start a
persistent relay or connect to your Minecraft instance.
