# GUMIHO 0.8.9 - paired-version combat test builds

## Install the correct build

| Minecraft | NeoForge build baseline | Java | JAR |
| --- | --- | --- | --- |
| 1.21.1 | 21.1.248 | 21 | gumiho-neoforge-0.8.9-mc1.21.1.jar |
| 26.2 | 26.2.0.75 | 25 | gumiho-neoforge-0.8.9-mc26.2.jar |

Use separate profiles. Keep the previous JAR and a copy of config/gumiho.json for rollback.
Close Minecraft, replace only GUMIHO in the matching profile, then restart. Enable only one
GUMIHO JAR per profile. Do not install this client mod on the dedicated server.
These builds do not allow different Minecraft versions to join an incompatible server.

The 26.2 port is native NeoForge; it does not require Connector or Forgified Fabric API.
Check every other mod's 26.2 support separately. Do not reuse 1.21.1 dependencies or upgrade
an existing world to test the port.

## Shared changes

- Both builds display their game version next to v0.8.9.
- Brand HUD sizes itself to fit that label.
- Tridents now count as melee weapons for Melee Aim and Cooldown Attack.
- Auto Weapon preserves a held trident as well as a mace.
- Existing target categories, player groups, manual overrides, shield attack windows,
  native cooldown gates and server allowlisting remain in force.
- Existing configuration values are retained. New spear modules default OFF.

## Spears: 26.2 only

There are no native spears in 1.21.1, so that build has no spear module or settings button.
Nothing is added to the item registry. A third-party 1.21.1 spear mod would need a separate
integration with its actual weapon mechanics.

### Combat > Spear Assist | 창 보조

OFF by default. Requires single-player or an explicitly allowlisted private server.
Uses the native spear tag, piercing component and attack-range component, covering native
material variants without hardcoding one spear item.

- **Spear Aim:** frame-eased aim within the weapon's native minimum/maximum reach band.
  Uses the existing target filters, FOV, priority, pin and melee speed/easing settings.
- **Aim While Charging:** permits that aim assistance while you manually hold Use with
  the main-hand spear. It does not press Use, move you, charge for you or change damage.
- **Allow Cooldown Jabs:** permits automatic native jabs only when Cooldown Attack is
  also enabled, full native cooldown is ready, and item use/cooldown rules allow a jab.

Right-click Spear Assist or Spear Status for these three settings. Turn Spear Aim off if
you want manual aim with automatic cooldown jabs.

Jabs use the native piercing attack packet, not the ordinary single-entity sword attack.
The full client-side native trace is checked: any excluded/protected entity cancels the
entire automatic jab. Walls block the trace. Wait for Hurt / Avoid Shields options apply.
This cannot guarantee protection against a player moving into the server's trace after
network delay. Manual attacks and manual charge damage remain ordinary game actions.

### Combat > Spear Status | 창 상태

OFF by default; informational and independently toggleable.

- Native jab cooldown percentage.
- Native minimum/maximum reach.
- Estimated charge state: WINDUP, READY, TOO SLOW, EXPIRED, or UNKNOWN.
- A tilde (~) means no current trace target: relative speed is an estimate.
- Safe jab line reports targeting eligibility, not a guarantee that damage will occur.

Charge state reads native kinetic delay/damage conditions and motion. READY is not a
promise of a hit: server timing, collision, shields, latency and movement still decide it.
Manual spear use is not a thrown projectile; there is no fabricated spear flight path.

## 26.2 port details and limits

HUD/menu extraction, input events, item/components, native piercing attacks, container
clicks and world rendering have version-specific adapters. Projectile and mace indicators
submit immutable geometry through the new render pipeline. Access transformation permits
the existing opt-in mace air-input correction to update the renamed native input vector.

Projectile estimates still use the existing bounded simulation and supported projectile
families. Homing, explosions, enchantments, modded physics and server corrections are not
a complete physics simulation. Full modpack and multiplayer behavior is not certified by
compilation or mathematical tests.

No new Link backend, team-sharing service, elytra automation, automatic spear charge/use,
sprint/jump attack, guaranteed shield defense, damage bypass or fall-damage bypass is added.

## Acceptance checklist

Use a disposable private test world, then the consenting test server.

1. Open the menu with Left Shift (or your configured key). Verify v0.8.9 and the correct
   Minecraft version. Check category scrolling, right-click settings and HUD dragging.
2. Confirm previous allowlist/player groups/toggles survive. On a non-allowlisted server,
   protected automation must remain inactive. Emergency Disable must stop automation.
3. Test swords, axes, mace and trident: one attack per full cooldown, no hits during
   manual eating/charging, and no teammate/neutral targets. Keep melee range native.
4. With Auto Shield enabled, test manual attack handoff, automatic attack windows and
   projectile-priority reblocking. Manual Use/building must retain priority. Shield
   startup and damage that bypasses shields remain vanilla limitations.
5. Test held bow/crossbow/trident/throwable previews and in-flight paths from players/mobs.
   Verify depth-tested lines/markers, toggles, world changes and no render crashes.
6. In 26.2, enable Spear Assist + Cooldown Attack and select eligible mobs. At the native
   reach band, confirm paced native jabs. Move too close/far: no jab. Put a wall or protected
   teammate anywhere along the piercing line: the entire automatic jab must stop.
7. Disable Cooldown Attack: Spear Assist may aim but must never jab by itself. Disable
   Spear Assist: normal manual spear behavior remains. Test all native material variants.
8. Hold Use manually while moving: verify charge windup, speed/relative-speed and expiration
   feedback. Stop moving or let the damage window expire; do not interpret aiming as damage.
9. Test a spear with an offhand shield, and a trident both as melee and thrown/Riptide.
   Confirm manual use wins and automatic weapon selection does not replace the held weapon.
10. In 1.21.1, verify NO spear entries exist and repeat the existing mace/reset/shield
    checks before replacing the prior release in a regular play profile.
