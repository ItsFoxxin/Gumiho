# 0.9.1 - Startup and HUD fit
Keeps the 0.9.0 feature set on Minecraft 1.21.1 and 26.2.

## Fixed
- Saved enabled modules no longer access the Minecraft singleton during mod construction. Runtime hooks activate only once the client is ready; automation still requires the existing server authorization.
- Early input/render events are guarded until the client is ready.
- Per-panel HUD size: 50% to 125%, in 5% steps. Saved positions are preserved; no automatic rearrangement of the weapon stack.
- Empty tracker, effects and other snapshot panels use their current content height instead of reserving every possible row.
- HUD editor hides OFF panels by default; a button reveals them for editing without enabling modules. Only the selected panel gets an extra outline.
- HUD and kit presets now include panel sizes. Old presets remain readable. Older GUMIHO releases ignore sizes they do not support.

## Use without losing your layout
1. Replace the old GUMIHO JAR with the 0.9.1 JAR matching Minecraft. Keep the old JAR outside mods for rollback. Do not delete config/gumiho.json.
2. Open HUD Editor. Leave the bottom-left weapon stack as it is.
3. Hover a crowded panel and scroll to resize, or select it and use minus/plus. Try 65-75% for equipment, tracker and resources.
4. Drag panels if needed. Top-of-screen placement remains available.
5. Use Saved to save/export a named HUD layout with sizes. Done retains changes. Do not Reset a layout you want to keep; Reset now asks for confirmation.
6. OFF visibility affects only this editor, not gameplay module toggles.

## Verification
Both native builds and their logic regressions pass, including 25 startup-lifecycle checks against isolated engine fixtures, 10,779 HUD sizing checks, and 62 preset checks. Fixtures are excluded from runtime JARs.
Actual Minecraft launch, rendering, modpack compatibility and user layout acceptance remain in-game checks:
- Launch 26.2 with an existing config containing enabled modules; confirm no null-client startup crash.
- Check single-player and allowlisted/non-allowlisted multiplayer authorization.
- Resize a panel, restart, and confirm size and position persist.
- Export/import HUD to the other 0.9.1 game build; confirm positions/sizes transfer without changing combat toggles.
- Confirm weapon stack is unchanged at its default 100% size, no bar/text overlap, and hidden OFF panels return when requested.
- Test both low and high GUI scales, drag bounds, reset confirmation, and dynamic tracker/effects height.

This release does not include the unfinished movement development candidate or GUMIHO Link.
